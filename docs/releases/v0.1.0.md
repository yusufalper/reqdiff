# reqdiff v0.1.0

**Find staging vs production API differences in one command.**

The first public MVP compares actual HTTP responses without requiring an OpenAPI file.

## What is included

- Concurrent GET requests to two environments, each with its own credentials.
- JSON structure and value diffs, exact numbers, and ignore rules for dynamic fields.
- Bearer tokens, Basic Auth, API-key headers, and existing session cookies via environment variables.
- Status and selected response-header comparison, plus optional latency regression thresholds.
- Human-readable output and schema-versioned JSON reports for CI.
- Bounded requests, strict JSON parsing, credential redaction, and cancellation support.
- Docker build/test support and a synthetic local demo.

## Install

Download the archive matching your operating system and CPU below. macOS, Linux,
and Windows are available for amd64 and arm64. Verify the archive against
`checksums.txt`, extract it, and put the executable on your PATH.

With Go 1.26 or newer:

```sh
go install github.com/yusufalper/reqdiff/cmd/reqdiff@v0.1.0
```

```sh
reqdiff https://staging.example.com/users https://api.example.com/users
```

Exit codes: `0` equal, `1` differences, `2` operational error, `130` cancelled.

## MVP boundaries

GET and JSON responses only; empty responses are supported. Arrays match by index.
Automatic login and token refresh are not included. Latency is a single observed
request per environment, not a benchmark. Two matching HTTP error responses can
compare equal and produce warnings.

See the [README](https://github.com/yusufalper/reqdiff#readme) for authentication,
Docker, ignored fields, configuration, and CI scenarios.
