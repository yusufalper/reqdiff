# Changelog

## 0.1.0

Initial MVP.

- Compare two live GET responses, concurrently.
- Structural and value JSON diffs with precise numbers and ignored paths.
- Separate Bearer, Basic, API-key headers, and cookies per environment.
- Status, selected response headers, and optional latency regression threshold.
- Text and versioned JSON reports, stable exit codes, bounded requests.
- Docker builds, race-tested local fixtures, CI, and portable release archives.
